❓ TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Logo not showing?
  → Check logo.png exists in project root
  → Falls back to SVG logo.svg (included)

Shoe images blank?
  → Click shoe to open modal (shows placeholder if path wrong)
  → Admin can edit image path for any shoe

Admin can't login?
  → Username: admin
  → Password: style18admin
  → (Exactly as shown above)

Data not persisting?
  → Check if browser storage is enabled
  → Don't have private/incognito mode (use normal window)
  → Check DevTools: F12 → Application → localStorage

Messages not showing?
  → Logout then login as the target user
  → Check navbar for 📬 badge (number of unread messages)
