# 🚀 Quick Start — 2 Minutes to Launch

## Step 1: Open the Site

Double-click or open in your browser:
```
index.html
```

That's it! The site is live. No server needed.

---

## Step 2 (Optional): Add Your Logo

If you have `logo.png`:
- Place it in the project root folder
- The site auto-detects and uses it
- Falls back to SVG logo if not found

## Test It Out

### As a Customer 👤

1. Click **Sign Up** → Create account
2. Browse shoes → Click any shoe
3. Enter redeem code: `STYLE10`
4. Click "Find Us" → See store location

### As Admin 🔐

1. Open `/admin.html`
2. Login: `admin` / `style18admin`
3. Try:
   - Add a new shoe
   - Ban a user
   - Send a message

## Common Tasks

### Add a Shoe
1. Admin → Shoes
2. Fill form & click "Add Shoe"

### Message a User
1. Admin → Users
2. Find user → Click "📨 Message"
3. Type & send

### Ban Someone
1. Admin → Users
2. Click "Ban" on user row
3. User blocked on next login

### Issue Discount Code
1. Admin → Redeem Codes
2. Fill form & click "Issue Code"
3. Users can now use it

### Change Store Hours
1. Admin → Shop Settings
2. Update address & hours
3. Save
